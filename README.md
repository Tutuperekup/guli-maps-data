# guli-maps-data

Vector map data (PMTiles) and map assets for the **Guli Kartuli** app (Tbilisi / Georgia).

- Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, available under the Open Database License (ODbL).
- Tiles are cut from the [Protomaps](https://protomaps.com) daily OpenStreetMap build with `pmtiles extract`.
- Fonts: Noto Sans (SIL Open Font License), sprites and style: Protomaps basemaps (BSD-3-Clause), renderer: MapLibre GL JS (BSD-3-Clause).

Files are rebuilt automatically every month by GitHub Actions and published as release `latest`.
This repository contains only open map data and build scripts — no application code.
